# AI Marketing Video Studio

أداة ويب احترافية لإنشاء فيديوهات تسويقية بالذكاء الاصطناعي باستخدام أفاتارات
D-ID.

## المزايا

- اختيار أفاتار من عدة شخصيات جاهزة.
- رفع صورة المنتج ومعاينتها داخل الأداة.
- كتابة وصف المنتج وتوليد نص تسويقي مناسب.
- دعم دارجة مغربية، خليجية، إنجليزية، وفرنسية.
- توليد فيديو أفاتار عبر D-ID API.
- معاينة وتحميل الفيديو الناتج.
- تصميم عصري باللونين البنفسجي والأسود.

## التشغيل المحلي

```bash
npm install
cp .env.example .env.local
npm run dev
```

ثم ضع مفتاح D-ID في `.env.local`:

```bash
D_ID_API_KEY=your_d_id_api_key
```

يدعم المتغير إما قيمة المفتاح كما يوفرها D-ID أو صيغة:

```bash
D_ID_API_KEY=username:password
```
